# KriSearch

**KriSearch** — это консольное Python-приложение для поиска фильмов в базе данных **Sakila**.

Проект позволяет искать фильмы по названию, по жанру и диапазону годов, показывает результаты постранично, а также сохраняет историю поисков в MongoDB и выводит статистику популярных запросов.

---

## Возможности проекта

В приложении реализовано:

* поиск фильмов по ключевому слову в названии;
* поиск фильмов по жанру и диапазону годов;
* вывод результатов по 10 фильмов на страницу;
* проверка пользовательского ввода;
* логирование поисковых запросов в MongoDB;
* вывод статистики:

  * топ-5 популярных запросов;
  * последние 5 уникальных запросов;
* красивый вывод таблиц через `tabulate`;
* smoke-тесты для быстрой проверки основных частей проекта.

## Как работает приложение

После запуска пользователь видит главное меню:

```text
KriSearch

1. Поиск по названию
2. Поиск по жанру и годам
3. Статистика
4. Выход
```

### 1. Поиск по названию

Пользователь вводит ключевое слово, например:

```text
AIR
```

Программа ищет фильмы, в названии которых есть это слово.

Результаты выводятся таблицей. Если фильмов больше 10, приложение предлагает показать следующую страницу.

---

### 2. Поиск по жанру и годам

Программа показывает список жанров и доступный диапазон годов.

Пользователь выбирает номер жанра и вводит годы:

```text
Введите номер жанра: 1
Год с: 2000
Год до: 2012
```

После этого приложение показывает найденные фильмы.
Результаты также выводятся постранично по 10 фильмов.

---

### 3. Статистика

Каждый поиск сохраняется в MongoDB.

В статистике можно посмотреть:

* **Top 5 popular searches** — самые популярные поисковые запросы;
* **Latest 5 unique searches** — последние 5 уникальных запросов.

Одинаковым запросом считается комбинация:

```text
search_type + params
```

Например:

```text
keyword + AIR
```

или:

```text
genre_years_range + genre_id 1 + years 2000-2012
```

## Логирование в MongoDB

При каждом поиске в MongoDB сохраняется документ примерно такого вида:

```python
{
    "timestamp": "2026-08-17T08:04:29.584890+00:00",
    "search_type": "keyword",
    "params": {
        "keyword": "AIR"
    },
    "results_count": 7
}
```

Для поиска по жанру и годам:

```python
{
    "timestamp": "2026-08-17T08:10:22.123456+00:00",
    "search_type": "genre_years_range",
    "params": {
        "genre_id": 1,
        "year_from": 2000,
        "year_to": 2012
    },
    "results_count": 25
}
```

Пагинация не логируется как отдельный поиск.
Если пользователь просто нажимает “показать следующие 10”, новый лог не создаётся.

## Smoke-тесты

В проекте есть файл:

```text
smoke_tests.py
```

Он быстро проверяет, что основные части приложения работают:

* подключение к MySQL;
* получение жанров;
* получение диапазона годов;
* поиск фильмов по названию;
* поиск фильмов по жанру и годам;
* подключение к MongoDB;
* запись тестового лога;
* получение статистики из MongoDB.

Запуск smoke-тестов:

```bash
python smoke_tests.py
```

Если всё работает, в консоли появится:

```text
Running MySQL smoke test...
MySQL smoke test passed.
Running MongoDB smoke test...
MongoDB smoke test passed.

All smoke tests passed.
```

Тестовые записи в MongoDB сохраняются с:

```text
search_type = "test"
```

Они не попадают в пользовательскую статистику.

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ivanovkristian2000-tech/KriSearch.git
cd KriSearch
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
```

### 3. Активировать виртуальное окружение

Для Windows:

```bash
.venv\Scripts\activate
```

Для Linux/macOS:

```bash
source .venv/bin/activate
```

### 4. Установить зависимости

```bash
python -m pip install -r requirements.txt
```

### 5. Создать файл `local_settings.py`

Файл `local_settings.py` должен быть создан локально.
Он не хранится в GitHub.

Пример структуры:

```python
HOST = "your_mysql_host"
USER = "your_mysql_user"
PASSWORD = "your_mysql_password"
DATABASE = "sakila"

dbconfig = {
    "host": HOST,
    "user": USER,
    "password": PASSWORD,
    "database": DATABASE,
}

MONGODB_URL_WRITE = "your_mongodb_write_url"
```

В реальном проекте сюда нужно добавить свои данные подключения.

### 6. Запустить приложение

```bash
python main.py
```

## Основные файлы

### `main.py`

Главный файл приложения.
В нём находится главное меню и обработка действий пользователя.

### `mysql_connector.py`

Содержит подключение к MySQL и методы для поиска фильмов:

* `get_genres()`
* `get_year_range()`
* `search_by_title()`
* `count_by_title()`
* `search_by_category_and_years()`
* `count_by_category_and_years()`

### `mongo_connection.py`

Общий класс подключения к MongoDB.
Используется для логирования и статистики.

### `mongo_logger.py`

Отвечает за запись поисковых запросов в MongoDB.

### `log_stats.py`

Получает статистику из MongoDB:

* топ популярных запросов;
* последние уникальные запросы.

### `formatter.py`

Отвечает за красивый вывод данных в консоль через `tabulate`.

### `smoke_tests.py`

Содержит простые smoke-тесты для проверки основных частей приложения.
